# Dependencies and assets

The GLB model and generator in this delivery were created for this implementation. They do not reuse a downloaded third-party model. The source does not include third-party font binaries; Geist is requested through declared package dependencies.

The repository uses React, Next.js, Vite, Tailwind, Radix, TanStack, React Flow, Motion, Three.js/React Three Fiber, Lucide, FastAPI, SQLAlchemy, Alembic, Pydantic, Argon2, Cryptography, HTTPX, Boto3 and Boost JSON. Verify the installed versions' licenses and supply-chain security and generate an SBOM from the reviewed dependency locks before release. No corporate endorsement, compliance certification or upstream ownership is implied by this implementation.

`artifacts/` contains build/test evidence only; runtime secrets, local user data, installed dependencies and font files are deliberately excluded from the source archive.
